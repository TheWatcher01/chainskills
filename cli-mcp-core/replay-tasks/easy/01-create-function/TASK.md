# Task: Creer une fonction slugify

## Instructions

Cree un fichier `/tmp/replay-test/slugify.ts` contenant une fonction TypeScript `slugify(text: string): string` qui :
- Convertit en minuscules
- Remplace les espaces par des tirets
- Supprime les caracteres speciaux (garde lettres, chiffres, tirets)
- Supprime les tirets en debut/fin
- Remplace les tirets multiples par un seul

Inclus 3 exemples d'utilisation en commentaire.

## Criteres de reussite
- Le fichier existe
- La fonction est exportee
- Les 3 exemples sont corrects
